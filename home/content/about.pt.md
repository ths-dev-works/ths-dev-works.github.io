## Stack Técnico

### Linguagens & Core
- **Go (Golang)** — Linguagem principal para microserviços e sistemas de alta performance

### Bases de Dados
- **PostgreSQL** — Base de dados relacional para cargas de trabalho transacionais
- **MongoDB** — Base de dados NoSQL para modelos de dados flexíveis

### Mensageria & Filas
- **NATS** — Mensageria leve para comunicação entre microserviços
- **NSQ** — Sistema de filas de mensagens distribuído

### Cloud & DevOps
- **Kubernetes** — Orquestração de contentores e gestão de clusters
- **Docker** — Contentorização e deployment
- **AWS** — Infraestrutura e serviços cloud
- **GCP** — Serviços Google Cloud Platform
- **CI/CD** — GitLab CI, GitHub Actions, Drone.io

### Monitorização & Observabilidade
- **Prometheus** — Recolha de métricas e alertas
- **Grafana** — Visualização e dashboards
- **Loki** — Agregação de logs

### Competências Principais
- Arquitetura de sistemas distribuídos
- Design e implementação de microserviços
- Otimização de performance
- Engenharia de escalabilidade
- Observabilidade e monitorização
